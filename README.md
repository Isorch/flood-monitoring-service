# Веб-сервис оперативного мониторинга паводков

Прототип сервиса для отображения зон затопления по SAR-данным Sentinel-1.
Регион демонстрации: Астраханская область (дельта Волги и ЗПИ).

## Стек
- Python 3.11, Flask, geopandas, rasterio
- SNAP (ESA) для предварительной обработки SAR
- Leaflet для карты (OSM + Esri World Imagery)

## Структура
- `app/` — Flask-приложение
- `scripts/` — CLI-скрипты обработки
- `snap_graphs/` — графы обработки SNAP
- `data/` — данные (не для Git)

## Логика работы
Сайт показывает ОДНО актуальное событие из `data/current/`.
Обработка выполняется отдельным процессом (`scripts/process_scene.py`),
результат атомарно заменяет содержимое `data/current/`.
